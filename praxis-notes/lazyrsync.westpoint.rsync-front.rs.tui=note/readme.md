[src/gh]: https://github.com/westpoint-io/lazyrsync.git "(MIT) (Languages: Rust 99.5%, Shell 0.5%) 🦀 A friendly terminal UI for rsync, written in Rust. Reusable profiles, an honest dry-run diff, and live progress, even over SSH. // 🦀 一个用 Rust 编写的友好的 rsync 终端界面。可重用配置文件、真实的运行差异对比以及实时进度，即使通过 SSH 也能查看。 /// A terminal UI for rsync 🔄 // rsync 的终端界面🔄 /// A terminal UI for rsync — manage reusable profiles, preview a transfer as a structured diff before running it, and watch a live run with progress and cancellation. All from the terminal, including over SSH where a desktop GUI can't reach. // rsync 的终端用户界面——管理可重用的配置文件，在运行传输前以结构化差异的形式预览传输，并实时查看运行进度和取消操作。所有操作均可在终端中完成，包括通过 SSH 连接，而桌面图形界面无法访问 rsync。 /// Why // 为什么 /// rsync is the right tool for backups and syncs, but its flags are easy to get wrong and a single mistake can delete data. lazyrsync keeps you in the terminal while giving you the safety of a GUI: save your transfers once, see exactly what a run will change before it runs, and keep destructive flags behind a gate. // rsync 是备份和同步的理想工具，但它的参数很容易出错，一个错误就可能导致数据丢失。lazyrsync 让你无需离开终端，即可享受图形界面的安全性：只需保存一次传输，即可在运行前准确查看每次运行的更改，并将可能造成数据丢失的参数隐藏起来。 /// Features // 特征 /// - Profiles & tasks // 个人资料和任务 ///: Save a Source → Destination pair once and rerun it with a keystroke. // 保存一次源→目标对，然后按一个键重新运行它。 /// - Dry-run preview  试运行预览 ///: Press p and watch the transfer resolve into a +/~/- diff with stats. Nothing is written until you say so. // 按下 p ，即可查看传输结果，结果会以 + / ~ / - 的形式显示差异和统计数据。在你手动操作之前，不会写入任何内容。 /// - Live run & cancel // 实时运行和取消 ///: r runs it — a progress bar fills with byte and file counts. Press c to stop mid-transfer. // r 运行该程序——进度条会显示字节数和文件数。按 c 可在传输过程中停止。 /// - Flags & --delete gating // 标志和 --delete 门控 ///: Toggle rsync's options as checkboxes. Flip on --delete and it makes you confirm before anything can be removed. // rsync 的选项以复选框的形式切换。启用 --delete 选项后，在删除任何文件之前，都需要您确认。 /// - Over SSH // 通过 SSH ///: Put a user@host:/path on either side of a task and it runs over SSH — remote source downloads, remote destination uploads. // 在任务的两端加上 user@host:/path ，即可通过 SSH 运行——远程源下载、远程目标上传。 /// - Snapshots // 快照 ///: Keep numbered, hardlinked versions with --link-dest — each run writes the next directory (1/, 2/, …). // 使用 --link-dest 保留编号的硬链接版本——每次运行都会写入下一个目录（ 1/ 、 2/ 、…）。 /// rsync 3.1 or later must be on your $PATH — the preview needs --itemize-changes, the progress bar needs --info=progress2 (added in 3.1.0) and snapshots need --link-dest. The Homebrew and AUR packages pull rsync in; cargo install and cargo binstall do not. // rsync 3.1 或更高版本必须添加到您的 $PATH 中——预览需要 --itemize-changes ，进度条需要 --info=progress2 （3.1.0 版本新增），快照需要 --link-dest 参数。Homebrew 和 AUR 软件包会引入 rsync； cargo install 和 cargo binstall 则不会。"
